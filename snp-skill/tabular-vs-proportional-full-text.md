# Tabular vs Proportional
Text from the video, recorded 2026-11-25.

Two digit systems exist, but most fonts hide one. Ledgers needed aligned columns, so tabular figures were built for that. Proportional digits vary in width, while tabular digits lock to one width. Tabular isn't guaranteed by default. Skip that check and prices misalign, timers jump, columns drift.

Tabular = fixed width, for alignment. Proportional = variable width, for running text. Use tabular where digits must line up, keep proportional everywhere else.
