# 20 Practical Design Tips
Spoken text from the video, recorded 2026-11-25.

1. Left-align long text
It is easier to read because every line starts in the same place. Bold section example: 1 to 16 (lines of a blog post intro paragraph, then the bold section: subheading followed by one paragraph, or multiple).

2. Text fills half the button
This padding, 10px 20px, ensures the button isn't too tight or too spacious.

3. Keep body text regular
Regular body text is easier to read. Avoid font-weight 600, which is too bold. Font-weight 400 is better.

4. Tint your grays blue
Gray can feel cold and lifeless, but adding a touch of blue makes it feel more natural. --gray-100: #e8eef9.

5. Keep Delete far from Save
People sometimes click Delete by accident. Placing it on the opposite side (margin-right: auto) helps avoid mistakes.

6. Tight headline line height
For large text, use a line height of 1.1 to reduce spacing between lines. Headline: Getting Started. Line height: 1.1.

7. Layer your shadows
Use multiple small shadows instead of one large shadow for a more realistic effect. 0 1px 2px rgba(0,0,0,0.04), 0 4px 12px rgba(0,0,0,0.06), 0 12px 32px rgba(0,0,0,0.08).

8. Use sentence case
It's easier to read because it's closer to how we write in everyday life. Title Case Is Harder To Read. Sentence case is easier to read.

9. Tint text on color
Using black text on a colored background can look harsh. Use a tinted version of the background color instead. Color: #92400e. Background: #fef3c7.

10. Align on the baseline
When elements of different sizes are next to each other, aligning on the baseline makes it look intentional. align-items: baseline.

11. Labels, not placeholders
Placeholders disappear when you start typing, but labels stay visible. Use a label.

12. One hue per color
A color has one hue. When you vary lightness or saturation, keep the hue the same. H:216 S:100% L:60%. H:216 S:90% L:52%. H:216 S:80% L:44%.

13. More padding on the sides
Give buttons more padding on the sides than on the top and bottom for a balanced look. Padding: 12px 24px.

14. Say what buttons do
Generic labels like "Submit" don't tell you what will happen. Clear labels like "Pay $48.00" do.

15. More space above headings
Increase the space above headings to make sections clearer. Margin: 48px 0 24px.

16. Mute colors in dark mode
Bright colors can feel too strong in dark mode. Use a softer, muted version instead. #8ab4f8.

17. Right-align numbers in tables
Numbers are easier to compare when their right edges line up. Total: 1,247 / 312 / 58.

18. Gap = small text's height
Spacing looks best when it matches the size of the smaller text. Font-size: 17px. Margin-top: 17px.

19. Add a CTA to empty states
An empty state is a chance to guide users to their next step. Get started.

20. Bigger landing page CTAs
On a landing page, you want people to notice the CTA. Making it much bigger than a normal button helps. Normal button font-size: 16px. Landing page CTA font-size: 34px.
