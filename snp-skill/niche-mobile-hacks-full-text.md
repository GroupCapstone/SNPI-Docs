# 10 Niche Mobile Hacks
Spoken text from the video, recorded 2026-11-25.

Intro: Here are 10 niche mobile hacks to make your website feel like it's native.

1. 16px inputs
iPhones zoom in on any input under 16 pixels, so make it at least 16 pixels.

2. No tap highlight
Links and buttons flash grey when you tap them, so turn off the tap highlight.

3. Numeric inputmode
Number fields shouldn't open the full keyboard, so set inputmode to numeric to get the number pad.

4. Hover media query
Hover styles get stuck after you tap, so instead put them inside a hover media query.

5. OTP autofill
Don't make people type the code from the text. Add autocomplete one-time-code and it autofills.

6. Overscroll contain
If scrolling a popup scrolls the page behind it, add overscroll-behavior contain.

7. Email input type
Email fields shouldn't start with a capital letter, set input type to email.

8. No double-tap zoom
If touching a button zooms in the page, set touch-action to manipulation.

9. Enter key hint
In a chat, the return key should say send. Set enterkeyhint to send.

10. Scroll snap
If your carousels stop halfway between cards, add scroll snap so every swipe lands on a card.
