# Side Navigation, 8 Ways to Open a Menu
Text from the video, recorded 2026-11-25.

1. Overlay
Overlay drawer: the menu slides over the page

2. Push
Push drawer: the page moves aside to make room

3. Reveal
Reveal: the page steps back, the menu shows

4. Icon rail
Icon rail: always there, takes little space

5. Expanding
Expanding rail: labels only when you need them

6. Accordion
Accordion: groups that open in place

7. Two-level
Two-level: sections on the left, pages beside

8. Floating
Floating panel: a sidebar that feels light
