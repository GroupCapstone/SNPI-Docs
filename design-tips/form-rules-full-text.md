# Your Form Makes Users Guess
Spoken text from the video, recorded 2026-11-25.

Intro: Your form makes users guess.

1. Use one full-name field
Since not every name splits into first and last

2. Put a visible label above every field
Since placeholders vanish while typing

3. Mark fields as required or optional
Whichever is rarer

4. Keep it to one column
Except for date and card data

5. Split long forms into steps

6. Set the input type and autocomplete for every field

7. State formats before typing
Not in the error

Closing line: Parsed, not guessed.
