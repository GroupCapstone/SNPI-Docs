Get started with package installation and repository cloning.
Run npm install to bootstrap monorepo workspaces and shared packages.
CORE SETUP
git clone <REPO_URL> && npm install
Verify runtime environments before initiating builds.
Requires Node.js >= 22.13.0, npm >= 10.8, and MongoDB Replica Set (rs0).
RUNTIME
node -v && mongod --replSet rs0
Execute the five-stage local development orchestration.
Step 1: npm run build:shared. Step 2: npm run dev:backend. Step 3: npm run dev:frontend.
PIPELINE
npm run build:shared && npm run dev
Define environment configurations across workspaces.
Populate .env with BACKEND_INTERNAL_URL, MONGO_URI, and JWT secrets.
ENVIRONMENT
MONGO_URI=mongodb://localhost:27017/snp_sms?replicaSet=rs0
Explore interactive components in the Developer Documentation Library.
Navigate to /document/design-system to review live components, states, and prompt skills.
DOCUMENTATION
Tailor component tokens and theme variables.
Override CSS variables or pass custom variant props without touching global CSS.
DESIGN TOKENS
Configure nested navigation hierarchies and subcategories.
Support multi-tier navigation trees with indented SVG rail paths and filleted bends.
HIERARCHY
Production enterprise pillars for the SNPI-SMS platform.
7-layer modular monolith, constant-time crypto, and WCAG AA/AAA compliance.
ENTERPRISE
npm run smoke && npm run test:api && npm run deploy:verify
