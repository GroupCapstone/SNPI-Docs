How does the modular monolith preserve tenant isolation?
Every Mongoose schema automatically enforces mandatory schoolId and branchId filters on all reads, updates, and ACID transactions. Express middleware guarantees client-supplied scopes are never trusted.
Are permissions enforced client-side or server-side?
All RBAC scopes are strictly verified server-side inside Express middleware against @snp/shared contracts using constant-time crypto.timingSafeEqual comparison for token hashes.
How do responsive device previews work in this library?
The Phone and Web toggles adjust the preview viewport container in real-time with CSS container queries without modifying application code or affecting live production routes.
Why are all UI components built developer-library first?
Per repository policy, all new components, dark modes, and designs are built and demoed in the developer portal (/document/design-system) first. They are never injected into the real dashboard without explicit user commands.
