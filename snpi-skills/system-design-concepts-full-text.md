# 10 System Design Concepts to Pass Interviews
Spoken text from the video, recorded 2026-11-25.

1. Object Storage
Use object storage when you need to store things like images, video or audio

2. CDN
CDNs cache content closer to users so media objects load faster

3. Caching
The easiest way to improve database performance is by adding a cache for frequently asked data

4. Load Balancing
Load balancers spread traffic across multiple servers to keep your server usage balanced

5. Database Scaling
Scale your database vertically by using a bigger server, and scale horizontally by adding multiple servers

6. Rate Limiting
Limit how many times someone can call your API through a rate limiter

7. Serverless
Serverless runs your code without managing a server. You can scale up to keep up with traffic demands, or scale down to zero when nothing happens

8. Read Replicas
Primary databases handle the writes, and read replicas copy the data and handle database reads

9. Message Queues
Have work wait in line to prevent services from being overloaded by pulling messages off of a queue

10. Observability
Observability helps you understand how your system is performing through logs, metrics and traces
