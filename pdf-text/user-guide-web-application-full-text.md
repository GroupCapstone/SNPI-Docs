# Web Application (Employee)

## I. Login Page

### 1. Login

You can go to the Web Application by private web link, for example: your private web link.

Access to your Web Application via many browsers like: Chrome, Safari, Firefox, Opera, Microsoft Edge, etc.

After access to your private web link, you can login to the Web Application by input your Username and Password.

### 2. Forgot Password

When you forgot your password, you can reset the password by using Forgot Password.

1. Input your Work Email
2. Click on Reset Password link that sent to your email
3. Enter your new password

Steps shown in the screenshots: Forgot Password, Email, Reset New Password.

## II. Account and Security

### 1. Update Password

After login to the Web Application you can update your password by: Click on your profile > Account and Security > Update Password.

Steps shown in the screenshots: Click on Profile, Click on Update Password, Update New Password.

### 2. Login Sessions

You can check login sessions to view how many device and browser currently is login on your account. For more security, if not know that it is your device you can Terminate it one by one or all sessions.

Steps shown in the screenshots: Click on Profile, Click on Login Sessions, Login Sessions.

## III. Attendance

### 1. Clock In

On the Web Application you able to do attendance Clock In as normal like mobile application too.

Steps shown in the screenshots: Dashboard > Clock In, Clock In.

### 2. Update Project Timesheets

When you are already Clock In you'll able to update your project timesheet by input what is your progress and worked hour on that project.

Steps shown in the screenshots: Dashboard > Project Timesheets, Project Timesheets.

### 3. Clock Out

On the Web Application you able to do attendance Clock Out. While you are clock out from web application you can update your project timesheet too.

Steps shown in the screenshots: Dashboard > Clock Out, Clock Out.

## IV. Requests

### 1. Short Break

Short Break is a feature that you can request a short leave: 15min, 30min, 1h, 1.5h and 2h. It'll help you to inform your direct manager that you are request a short break.

Steps shown in the screenshots: Dashboard > Request (1), Short Break (2), Short Break > Apply (3), Short Break > Apply > Step1 (4), Short Break > Apply > Step2 (5).

### 2. Time Off

Time Off is a feature that you can request long leave from half day to maximum per request base on your leave type. It will help you to inform your direct manager that you are request a leave.

Steps shown in the screenshots: Dashboard > Request (1), Time Off (2), Time Off > Apply (3), Time Off > Apply > Step1 (4), Time Off > Apply > Step2 (5).

### 3. Schedule Request

Schedule Request is a feature that you can request to move your working shift to another day. This feature is able for only employee schedule base.

Steps shown in the screenshots: Dashboard > Request (1), Schedule Request (2), Schedule Request > Add One (3), Schedule Request > Add One (4).

### 4. Overtime

Overtime is a feature that you can request working overtime. It will help you to inform your direct manager that you want to working overtime.

Steps shown in the screenshots: Dashboard > Request (1), Overtime (2), Overtime > Add One (3), Overtime > Add One (4).

### 5. eForm

eForm is a feature that you can create a form base on your company eform template.

Steps shown in the screenshots: Dashboard > Request (1), eForm (2), eForm > Add One (3), eForm > Add One > Step1 (3), eForm > Add One > Step2 (4).

## V. Performance

### 1. KPI

KPI is a feature that able you to create working plan or target. You can create many KPI base on your company KPI.

Steps shown in the screenshots: Dashboard > Performance (1), Performance > KPI (2), KPI > New KPI (3), KPI > New KPI (4), KPI > Update Progress (5), KPI > Update Progress (6), KPI Listing (7).

## VI. Recruiting

### 1. View Job Posting

At Recruiting you can view Job Posting of your company.

Steps shown in the screenshots: Dashboard > Recruiting (1), Recruiting (2), Recruiting > Job Posting (3), Recruiting > Job Board (4).

## VII. Payroll

### 1. View Payslip

You can view your payslip after your payroll is completed. At Payslip detail you can print and download your payslip.

Steps shown in the screenshots: Dashboard > Payroll (1), Payroll Listing (2), Payroll > Payslips (3), Payslip Detail (4).

# Web Application (Manager)

## VIII. Short Break

### 1. Request Short Break

Path: Request > Short Break > People

As a manager you are able to apply short break for your subordinate by go to Short Break > People > Select your subordinate and click on apply.

### 2. Approve Short Break

Path: Request > Short Break

As a manager you are able to approve short break request from your subordinate by go to Short Break listing or People click on action approve.

### 3. Unapprove Short Break

Path: Request > Short Break

After short break approved you are still able to unapproved it back to edit or delete it. Go to Short Break Listing or People click on button approved to unapproved.

### 4. Deny Short Break

Path: Request > Short Break

As a manager you are able to deny short break request from your subordinate by go to Short Break listing or People click on action deny.

## IX. Time Off

### 1. Leave Request

Path: Request > Time Off > People

As a manager you are able to apply leave for your subordinate by go to Time Off > People go to there name and select apply. Select Leave type, from date, to date and reason leave of your subordinate.

### 2. Approve Leave Request

Path: Request > Time Off

As a manager you are able to approve Leave request of your subordinate by go to Time Off listing or People click on action approve.

### 3. Unapprove Leave Request

Path: Request > Time Off

After Leave Request approved you are still able to unapproved it back to edit or delete it. Go to Time Off Listing or People click on button approved to unapproved.

### 4. Deny Leave Request

Path: Request > Time Off

As a manager you are able to deny Leave Request request from your subordinate by go to Time Off listing or People click on action deny. After denied if your subordinate doesn't have timesheet on time off request date, Leave denied will count as Unpaid leave in Payroll.

## X. Schedule Request

### 1. Schedule Request Approval

Path: Request > Schedule Request > Request Detail

You are able to Approve / Deny / Edit your subordinate request change schedule by go to Schedule Request > Request Detail > Action.

## XI. Over Time

### 1. Overtime Approval

Path: Request > Overtime > Overtime Request

You are able to Approve / Deny / Edit / Delete and Unapproved your subordinate request overtime by go to Overtime > Overtime Request > Action.

## XII. eForms

### 1. eForm Approval

Path: eForm > eForm Request

You are able to proceed the eform request from your subordinate by click from Alert Notification or go to eForm listing.

## XIII. Time Tracking

### 1. Add Timesheet

Path: Time Tracking > People > Add Hour

You are able to add working hour for your subordinate by go to Time Tracking > People > Add Hour.

### 2. Edit Timesheet

Path: Time Tracking > People > Timesheet = Edit

You are able to edit your subordinate timesheet by go to Time Tracking > People > Timesheet = Edit, or go to Time Tracking > Timesheet > Select Date = Edit.

### 3. Approval Timesheet

Path: Time Tracking > People > Timesheet

You are able to Approve / Deny your subordinate time attendance, you can approve by Timesheet date or by Per employee profile.

- Timesheet Date = Time Tracking > Timesheet Date > Action Approval
- Per Employee Profile = Time Tracking > People > Action Approval

## XIV. Schedule

### 1. Create Schedule

Path: Time Tracking > Schedule

You are able to create or upload schedule for your subordinate.

- Create Schedule = Time Tracking > Schedule > Add Shift
- Import Schedule = Time Tracking > Schedule > Import (Download Template, Input Data and Upload back)

### 2. Edit Schedule

Path: Time Tracking > Schedule > Select Date > Edit

You are able to edit your subordinate shift by go to Schedule > Select Date > Edit. If you hard to find your subordinate you can using search.

### 3. Delete Schedule

Path: Time Tracking > Schedule > Delete

You are able to delete your subordinate shift by go to Time Tracking > Schedule > Delete.

## XV. KPI

### 1. Create KPI

Path: Performance > KPI > Filter Employee > New KPI

You are able to create KPI for your subordinate by go to Performance > KPI > Filter select employee name > New KPI. After created as you are a manager, you are able to Update, Edit and Delete that KPI.

### 2. Approve KPI Timeline

Path: Performance > KPI > Filter Employee

You are able to approve your subordinate Timeline History by go to view their KPI detail.

### 3. Approve KPI

Path: Performance > Team Dashboard > Select an employee

You are able to approve your subordinate KPI by go to Team Dashboard > Select their name. Note after approved KPI you and your subordinate are not able to update, edit and delete KPI timeline.
