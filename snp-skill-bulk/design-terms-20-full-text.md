# 20 Design Terms You Should Know
Spoken text from the video, recorded 2026-11-25.

1. Kerning
Spacing between a pair of letters

2. Optical centre
Centred by eye, not by math

3. Tabular numbers
Every digit is the same width

4. Layout shift
Content jumps as things load

5. Tracking
Even spacing across every letter

6. Optimistic update
Show the result before the server confirms

7. x-height
How tall the lowercase letters are

8. Touch target
The tappable area, not just the icon

9. Leading
The space between lines of text

10. Origin-aware animation
Animates out of what you clicked

11. OKLCH
Colour where equal lightness looks equal

12. Widow
One word alone on the final line

13. Safe area
Screen area clear of the notch and home bar

14. Stagger
Items animate one after another

15. Line length
About 65 characters per line reads best

16. Affordance
A visual cue for how to use something

17. Combobox
A text field that filters a list

18. Interruptible animation
Can change course mid-animation

19. Progressive disclosure
Show more only when it's needed

20. Shared element transition
One element grows into the next view
