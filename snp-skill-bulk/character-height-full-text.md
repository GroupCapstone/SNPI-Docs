# 5 mm Fails at 5 m (Character Height)
Text from the video, recorded 2026-11-25.

5 mm fails at 5 m. Fixed millimeter values ignore viewing distance entirely. 16' = absolute minimum, targets above. Phone 35 cm, target 20', about 2.0 mm. Desktop 60 cm, target 20', about 3.5 mm. Signage 5 m, target 30', about 44 mm.

Character Height: h = 2 · d · tan(θ / 2). h = character height, d = viewing distance, θ = target angle. The same formula applies to any medium and any distance. ISO 9241-303, DIN 1450, USSC.
