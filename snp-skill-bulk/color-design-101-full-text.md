# Color Design 101
20 terms you should know. Spoken text from the video, recorded 2026-11-25.

1. Simultaneous contrast
Context changes color

2. Tint
A color plus white

3. Chromostereopsis
Red on blue vibrates

4. Increase contrast mode
Contrast, turned up

5. Analogous colors
Wheel neighbors

6. Shade
A color plus black

7. Gamut
Range of colors

8. Tone
A color plus gray

9. Abney effect
White shifts the hue

10. Chroma
How colorful it is

11. Hue
Which color it is

12. Irradiation illusion
Bright looks bigger

13. Stevens' power law
Brightness isn't linear

14. Hunt effect
More light, more color

15. Additive color
Mixing colored light

16. Sequential scale
One hue, low to high

17. Helmholtz–Kohlrausch effect
Vivid looks brighter

18. Opacity
How see-through it is

19. Diverging scale
Two hues, gray middle

20. Relative luminance
How much light, 0 to 1
