Spoken text from the video, recorded 2026-11-25.

Fonts by role
Your fonts need job descriptions. The main font carries body text and buttons. A second font only gets hired for a job the main can't do, like headlines and quotes that set the tone. Decorative fonts never get the body text. Code gets a monospace font in the code blocks. Name font tokens by role, not by typeface.
